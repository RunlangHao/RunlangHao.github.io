# Introduction and Description

In this assignment, I explained the difference between Machine Learning and Deep Learning
by providing a real-world application for each type of technology, explaining why the approach
is suitable for the problem, and why the other approach is not suitable.

# Objective

The objective of this assignment is to compose an analysis on my findings from the research about the pros and cons of Machine Learning and Deep Learning. 

# Value Proposition

This activity deepens my understanding of different machine learning technologies and what kind of projects they are best fitted in. 

# Process

## Step 1: Research

I began this project by first researching the features, similarities, and differences between machine learning and deep learning. 

## Step 2: Proposal

Based on my findings from the research, I did some brainstorming and came up with an application for each type of machine learning where I think it is best suited for. 

For traditional machine learning, I chose smart appliances and robotics, where image recognition can be a useful feature and hardware resource is limited.

## Step 3: Revision

I asked Claude for some opinions on my ideas, and received corrections and feedback. One important details was that since deep learning is a type of machine learning, I must clarify I am referring to traditional machine learning techniques when writing the analysis. 

## Step 4: Composition

I started the composition only after clearing everything up. This ensured my writing was as accurate and efficient as possible. Some more clarifications were provided by Claude when I asked to double check the points.
